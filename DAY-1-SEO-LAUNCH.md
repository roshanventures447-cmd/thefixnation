## Google Search Console Steps

1. Open Google Search Console:
   https://search.google.com/search-console

2. Add property:
   Use Domain property if DNS access is available:
   `thefixnation.com`

   If DNS access is not available, use URL prefix:
   `https://thefixnation.com/`

3. Verify ownership.
   Best option for GitHub Pages:
   - Use HTML file verification if Search Console gives a file.
   - Upload that file to the website root.
   - Open the verification URL in browser.
   - Click Verify.

4. Submit sitemap:
   `https://thefixnation.com/sitemap.xml`

5. Use URL Inspection and request indexing for these first:
   - `https://thefixnation.com/`
   - `https://thefixnation.com/services.html`
   - `https://thefixnation.com/furniture-assembly-repair-hyderabad.html`
   - `https://thefixnation.com/furniture-assembly-repair-bangalore.html`
   - `https://thefixnation.com/furniture-assembly-repair-chennai.html`
   - `https://thefixnation.com/furniture-assembly-repair-pune.html`
   - `https://thefixnation.com/furniture-assembly-repair-mumbai.html`
   - `https://thefixnation.com/furniture-assembly-repair-kanpur.html`
   - `https://thefixnation.com/furniture-assembly-repair-varanasi.html`
   - `https://thefixnation.com/contact.html`

6. After indexing requests, check:
   - Pages > Not indexed
   - Sitemaps > Success
   - Experience > Core Web Vitals after data appears
